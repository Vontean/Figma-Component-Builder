# 热区

## 规则

1. **有容器直接用容器承载热区**：有明确 `container` 的交互组件，容器尺寸承载热区，不单独增加热区层。
2. **无容器使用独立热区层**：图标操作、可点击文本或无视觉容器的选择控件，需要独立的 `touch target` 层。
3. **热区大小不等于布局大小**：视觉主体按自身 token 布局；独立热区层与视觉主体解耦。
4. **不同元素热区不重叠**：同一组件内相邻可交互元素的热区必须分离，不相互覆盖。

## 独立热区层

- 命名为 `touch target`，除非项目已有等价命名约定。
- 尺寸绑定当前项目确认的最小触控目标 token 或数值。
- 层透明，不参与视觉；可向视觉主体周边溢出或居中扩展，但不改变组件布局尺寸。

## 验证

- 有容器组件：容器尺寸已覆盖最小热区，无多余热区层。
- 无容器组件：存在独立热区层，并符合最小触控目标。
- 不同元素热区无重叠。

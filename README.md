# VT Figma Skills

用于 Figma 组件库搭建与 token 命名的两个可安装技能， 记录 Figma 组件库搭建中可复用的执行规则和上下文。

## 结构

```text
.
├─ README.md
└─ skills/
   ├─ vt-component-builder/   构建、迁移与验证组件库组件
   └─ vt-token-naming/        命名与评审分层 token
```

## 安装

安装 `skills/` 下的目标技能目录，不安装仓库根目录。安装后可在每个技能目录创建 `data/links.csv`，保存该项目已确认的文件或页面链接。
